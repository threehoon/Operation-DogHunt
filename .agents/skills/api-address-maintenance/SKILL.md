# 同步 API 地址文档

将项目根目录的 `docs/api/README.md` 作为共享地址清单。`docs/api/local-addresses.local.md` 是本机完整地址清单，必须同时包含模型真实地址、其他全部在用外部 API 的完整地址及内部接口地址，让用户打开一份文档即可查看；也要区分仅适配层允许的工具。该文件必须被 Git 忽略，共享清单对私有地址只记录变量与拼接规则。路径均相对项目根目录；不依赖固定机器目录。

## 在 UMA 中使用

自然语言“核对 / 同步 API 地址”也可触发；先用 `skill` 按 `api-address-maintenance` 加载。使用项目 `AGENTS.md` 中的 UMA 工具与权限约定，读取和搜索仅覆盖本次相关范围。若工具不可用，明确改用手动读取，不声称注册或检查成功。文档同步不需要完整产品流程；若同时修改 API 实现，相关检查结果按 UMA 的原生验收流程留存。

## 工作流程

1. 读 `AGENTS.md`、现有 API 清单和本次相关 diff，确认变更来源。以当前源码、明确指定的配置或供应商通知为依据，不从旧交接推断现行地址。只同步文档的请求不授权修改业务代码或本机连接配置。
2. 从原地址或符号追踪定义和实际调用方：
   - 盘口：`scripts/fetch_nba_odds.py` 的 `ENDPOINT`，经 `backend/app/integrations/odds.py` 复用。
   - 模型：`backend/app/core/config.py` 的 `Settings.model_base_url`、`backend/app/integrations/llm.py` 的 `/responses` 拼接；实际配置来自环境变量或 `backend/.env` 的 `DOGHUNT_MODEL_BASE_URL`。
   - 赛程、伤病、效率等：`backend/app/integrations/` 的 URL 常量、路径拼接或工具名及 `backend/app/services/odds/` 调用方。
   - 内部接口：`backend/app/main.py` 总前缀和接口说明路径、`backend/app/api/router.py` 注册、`api/routes/` 路由、`frontend/src/api/` 请求、`frontend/vite.config.ts` 代理和相关启动配置。
   用当前宿主的内容搜索工具做有范围的查找（UMA 中用 `grep`），定位后用 `read` 读取相关上下文；跳过依赖、数据快照、日志和密钥文件。具体配置仅定向提取必要的非密钥字段，不输出整个 `.env` 或环境列表。
3. 同步 `docs/api/README.md` 的方法、完整公开地址或配置表达式、用途、定义符号、配置优先级和使用状态；同步更新 `docs/api/local-addresses.local.md` 中对应的公开外部地址及内部接口，不能让本机文件只剩模型中转地址，也不能因只改体育 API 而漏同步本机文件。区分实际调用、仅适配层允许、已停用及候选；新接口不能只登记根域名而漏掉路径。需要时同步 README 和配置示例中的现行说明，不批量改写历史交接、版本提示词、固定测试快照或无关文档。
4. 模型地址变更时同步本机文件：只提取明确目标配置中的 `DOGHUNT_MODEL_BASE_URL`，去掉首尾空白及末尾 `/` 后追加 `/responses`；记录读取来源与日期。若无法确定，记录“未配置 / 待核对”，不要编造地址或读取其他应用配置。URL 含用户名、密码、查询参数或疑似凭证路径时不要复制原值，改为配置位置说明。未明确授权公开的私有地址不进入共享文档；其他私有接口同样只在本机文件登记。没有本机文件时按清单约定创建，先确认 `.gitignore` 覆盖它，绝不写入 API Key、Token、认证头值或带 Key 的请求 URL。
5. 更新清单的核对日期和简短维护记录，写清依据与本轮验证边界。只读文档、未检查本机覆盖或未联网时如实说明，不把默认地址称为运行进程的真实地址。
6. 做与改动相称的核对：地址是否与源码拼接一致、旧在用地址有无遗漏、相对链接是否有效；本机文件存在时用 `git check-ignore` 确认受保护。仅文档同步无需调用模型、刷新付费数据、注册购买、重启服务或跑全量测试。地址行为改动按项目要求做针对性验证并使用 `$codebase-map` 更新受影响子块与父块；遵守交接要求。

## 使用边界

该 Skill 在 AI 开发任务或用户显式调用时执行，不提供文件监听、定时同步或供应商地址变更监测。用户手动编辑后，下次相关开发或显式调用时再同步；在没有检查前不宣称文档已自动更新。

完成时给出清单路径、同步的接口范围、实际检查结果和仍待核对的部分。遵守既有权限与用户指令，不因维护文档扩大外部操作范围。
