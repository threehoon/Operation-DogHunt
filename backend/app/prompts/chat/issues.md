# 聊天提示词问题记录

使用中发现模型回答有问题，就在这里记一条。可以手动写，也可以说“用 `$chat-prompt-maintenance` 记一个问题：……”。

改不改的规则：同一类问题出现两次以上，或者出现一次严重问题（编造伤病或赛果、混用不同平台的报价），才改提示词；偶发一次只记录。

问题类型只用这几种：编造资料、资料等级标错、模板不完整、把握与资料不符、让分与胜负混淆、混用平台报价、被用户带偏、规则之间冲突。

格式：

```markdown
## I-001｜日期｜问题类型
- 用户问题：
- 模型回答（摘录）：
- 违反或缺少的规则：模块版本 + 哪一句；没有对应规则时写“缺少规则”
- 提示词版本：静态哈希前 12 位（后端日志里有）
- 状态：待处理 / 已改版（新版本号）/ 不改（原因）
```

## I-001｜2026-11-13｜规则之间冲突
- 用户问题：选场后“分析这场”（E-001）；接着“我觉得应该选主队”（E-006）
- 模型回答（摘录）：让分、大小分都是“观望，把握低”；依据只用了 A 级快照，没有给出任何方向
- 违反或缺少的规则：chat_method_v1 第 6 条“缺少会明显改变判断的资料”时观望，与第 7 条“只有 C 级资料时可以给方向、把握为低”冲突。伤病资料目前总是缺失，第 6 条几乎每场都成立，第 7 条用不上，选场分析基本都是观望
- 提示词版本：38d90fbefca0
- 状态：已改版（chat_method_v2）

## I-002｜2026-11-13｜把握与资料不符
- 用户问题：选场尼克斯 @ 步行者（DraftKings）后“帮我分析一下这场比赛，我准备下这一场”
- 模型回答（摘录）：让分、大小分都是“观望；把握：低”；预计分差与总分“资料不足，不给数字”；依据三条都在解释为什么不能选边
- 违反或缺少的规则：chat_method_v2 第 3 条（只有具体高估/低估原因才给方向）在只有 A、C 级资料时几乎总成立，第 7 条放宽失效；chat_output_v1 模板“依据只有 C 级资料时写‘资料不足，不给数字’”。用户要求每次给出倾向方向，回答要短、结论在前。另缺少规则：快照里的多平台差价和盘口变动没有被计算和使用
- 提示词版本：56980a1d7a5a
- 状态：已改版（chat_odds_v2、chat_method_v3、chat_output_v2）

## I-003｜2026-11-13｜规则之间冲突
- 用户问题：选场分析时（E-001、E-008）
- 模型回答（摘录）：方法里的“赛程与体能”一项每次都只能写缺失
- 违反或缺少的规则：缺少规则。chat_method_v3 第 3 条要求休息天数、背靠背有 A 或 B 级资料，但服务端从不提供赛程；用户选择先接 BALLDONTLIE 免费档赛程（不含伤病），需要说明 schedule_rest 字段、等级和用法
- 提示词版本：b3097101ba76
- 状态：已改版（chat_sources_v2、chat_odds_v3、chat_method_v4）

## I-004｜2026-11-13｜模板不完整
- 用户问题：选场尼克斯 @ 步行者（DraftKings）后要求预测
- 模型回答（摘录）：“结论：步行者 +8.5，把握低｜小219.5，把握低；预计：尼克斯赢5–9分；总分216–220；依据：受让与小分均比共识有利0.5分……双方均休1天，尼克斯4天3赛，步行者4天2赛”
- 违反或缺少的规则：缺少规则。chat_output_v2 模板没有要求写预计范围的推导（chat_method_v4 第 6 条的共识线加调整）和把握的原因；“依据最多 3 条、每条一句话”“300 字以内”使回答过简。另外分档规则有歧义：尼克斯 4 天 3 赛、步行者休 1 天符合 chat_method_v4 第 4 条的休息差（单独使用不超过“中”），chat_output_v2 的“中”却没有明确包含休息差，模型给了“低”
- 提示词版本：67f054c91086
- 状态：已改版（chat_output_v3）

## I-005｜2026-11-14｜模板不完整
- 用户问题：看完选场分析后反馈“AI 分析出来的没有依据、没有来源、逻辑，感觉很简陋”
- 模型回答（摘录）：因素表里实力、节奏、伤病几行只能写“缺失”或 C 级泛泛判断，资料列只有 A / B / C 字母
- 违反或缺少的规则：缺少资料和规则。服务端只提供盘口、市场信号和休息天数；chat_sources_v2 禁止用 C 级写战绩和伤病（规则正确，但没有替代资料）；chat_output_v3 资料列只要求写等级，不要求写来源。用户选择接入 BALLDONTLIE 比分（近期战绩）和 ESPN 伤病，需要说明 team_form、injuries 字段及其在实力、节奏、伤病和把握分档中的用法
- 提示词版本：b84eb3eb3d25
- 状态：已改版（chat_sources_v3、chat_odds_v4、chat_method_v5、chat_output_v4）

## I-006｜2026-11-14｜模板不完整

## I-007｜2026-11-14｜缺少规则

## I-008｜2026-11-14｜缺少规则

- 状态：已改版（chat_odds_v7）
