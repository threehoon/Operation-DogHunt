用项目虚拟环境执行不联网的客户端初始化：默认 `httpx.AsyncClient()` 抛出相同 `InvalidURL`，而 `httpx.AsyncClient(trust_env=False)` 初始化成功。结合日志中 `URLPattern` 解析栈，定位为 httpx 读取环境代理例外名单时无法解析其中 IPv6 地址写法，并非模型返回认证或额度错误。

`integrations/balldontlie.py` 与 `integrations/espn.py` 同样默认创建 `httpx.Client`，因此也会受该环境解析问题影响。后台先取赛程、后取伤病；没有今天的保存文件与此相符，但终端保留片段没有这两项的具体失败日志，不将推断写成已观察到的供应商响应。
